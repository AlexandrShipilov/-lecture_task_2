# Домашнее задание — лекция 6 «Мобильное приложение на Kivy»

## Что реализовано

**Базовая функциональность (сделанное на лекции):**
- CRUD-операции с расходами, локальное хранилище JsonStore
- Список операций на RecycleView
- Аналитика расходов по категориям
- Экспорт данных в CSV
- Всплывающие окна ошибок

**Пункты домашнего задания:**
1. **Графики (Kivy Garden — matplotlib)** — экран «Аналитика (графики)»:
   круговая диаграмма структуры расходов по категориям и столбчатая
   диаграмма «Доходы vs расходы» через `FigureCanvasKivyAgg`.
2. **Синхронизация с облаком (REST API)** — класс `CloudSync`:
   скачивание облачных записей (GET), слияние с локальными
   (при конфликте побеждает более свежая запись по дате),
   выгрузка объединённого набора (PUT). Работает в фоновом потоке,
   совместим с Firebase Realtime Database REST API.
3. **Категории доходов и баланс** — операции двух типов (расход/доход)
   со своими категориями, на главном экране итоги:
   «Доходы», «Расходы» и «БАЛАНС = доходы − расходы».

## Установка и запуск

```bash
pip install kivy matplotlib kivy-garden.matplotlib
python main.py
```

Запускать только как обычный Python-файл (не из Jupyter/REPL —
иначе ошибка `OSError: source code not available`).

## Настройка синхронизации с облаком

В начале `main.py` задайте адрес сервера:

```python
SERVER_URL = 'https://<ваш-проект>-default-rtdb.firebaseio.com'
SYNC_PATH  = '/transactions.json'
```

или через переменную окружения `TRACKER_SERVER_URL`.
Для Firebase узел `/transactions.json` открывается в режиме
правил базы; для учебного REST-сервера достаточно эндпоинта,
принимающего `GET` и `PUT` с JSON вида
`{"ключ": {"type", "category", "description", "amount", "date"}}`.
